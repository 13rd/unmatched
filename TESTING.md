# Инструкция по тестированию многопользовательской игры

## Шаг 1: Запуск сервера

```bash
npm start
```

Сервер запустится на порту 3000.

## Шаг 2: Тестирование в одном браузере

### Создание комнаты (Игрок 1)

1. Откройте `http://localhost:3000/setup.html`
2. Нажмите **"Создать новую комнату"**
3. Загрузите фоновое изображение (background.png или background_crop.png)
4. Загрузите файл точек (points(2).json)
5. Выберите цвета для обоих игроков
6. Нажмите **"Начать игру"**
7. Скопируйте код комнаты (например: ABC123)

### Подключение к комнате (Игрок 2)

1. Откройте новую вкладку/окно в режиме инкогнито
2. Перейдите на `http://localhost:3000/setup.html`
3. Нажмите **"Присоединиться к комнате"**
4. Введите код комнаты
5. Нажмите **"Подключиться"**

## Шаг 3: Проверка синхронизации

### Что должно работать:

✅ **Перемещение фишек**: Перетащите фишку в одной вкладке - она должна переместиться во всех остальных
✅ **Изменение HP**: Измените HP в одной вкладке - значение обновится везде
✅ **Очистка поля**: Нажмите "Очистить поле" - все фишки исчезнут во всех вкладках
✅ **Подключение нового игрока**: Новый игрок видит текущее состояние игры

## Шаг 4: Тестирование на разных устройствах

1. Узнайте IP-адрес вашего компьютера:
   ```bash
   # Linux/Mac
   ifconfig | grep "inet "
   
   # Windows
   ipconfig
   ```

2. На другом устройстве в той же сети откройте:
   ```
   http://[ваш-IP]:3000/setup.html
   ```

## Возможные проблемы и решения

### Фишки не появляются
- Проверьте консоль браузера (F12)
- Убедитесь, что файл точек загружен корректно
- Перезапустите сервер

### Изменения не синхронизируются
- Убедитесь, что все используют один код комнаты
- Проверьте, что сервер запущен
- Проверьте консоль на ошибки WebSocket

### Ошибка "413 Payload Too Large"
- Уже исправлено в server.js (maxHttpBufferSize: 1e8)
- Перезапустите сервер
