## Как развернуть на VPS:

### Метод 1: Автоматический (рекомендуется)

```bash
# 1. Загрузите проект на VPS
scp -r /home/nikita/Python/unmatched_js_table user@YOUR_VPS_IP:~/

# 2. Подключитесь к VPS
ssh user@YOUR_VPS_IP

# 3. Запустите развертывание
cd ~/unmatched_js_table
./deploy.sh
```

### Метод 2: Ручной

```bash
# На VPS
cd ~/unmatched_js_table
docker-compose up -d
```

## Что дальше?

### Для production:

1. **Настройте домен:**
   - Укажите A-запись на IP VPS
   - Настройте Nginx reverse proxy
   - Установите SSL сертификат

2. **Безопасность:**
   - Настройте firewall: `sudo ufw allow 3000/tcp`
   - Отключите root SSH доступ
   - Установите fail2ban

3. **Мониторинг:**
   - Настройте логирование
   - Мониторинг ресурсов
   - Автоматические backup

4. **Оптимизация:**
   - Настройте лимиты ресурсов
   - Включите gzip сжатие в Nginx
   - Настройте кэширование

## Поддержка:

При возникновении проблем:
1. Проверьте логи: `docker-compose logs`
2. Проверьте статус: `docker-compose ps`
3. Проверьте порты: `sudo netstat -tulpn | grep 3000`
4. Проверьте firewall: `sudo ufw status`
