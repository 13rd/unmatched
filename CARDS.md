# Карточный движок - Документация

## Обзор

Карточный движок добавляет возможность работы с картами в многопользовательской игре. Каждый игрок имеет свою колоду и личное поле для карт, а также есть общее поле, куда все игроки могут выкладывать карты.

## Возможности

### Основные функции

- ✅ **Личные колоды** - у каждого игрока своя колода из 20 карт
- ✅ **Взятие карт** - игроки могут брать карты из своей колоды
- ✅ **Личные поля** - каждый игрок видит только свои карты на личном поле
- ✅ **Общее поле** - все игроки видят карты на общем поле
- ✅ **Переворачивание карт** - карты имеют рубашку и лицевую сторону
- ✅ **Drag & Drop** - перемещение карт между полями
- ✅ **Синхронизация** - все действия синхронизируются в реальном времени

## Структура

### Поля для карт

1. **Общее поле** (`sharedCardField`)
   - Видно всем игрокам
   - Сюда можно перемещать карты из личных полей
   - Все карты видны лицевой стороной

2. **Личное поле Игрока 1** (`player1CardField`)
   - Видно только владельцу
   - Карты появляются здесь при взятии из колоды
   - Можно перемещать на общее поле

3. **Личное поле Игрока 2** (`player2CardField`)
   - Видно только владельцу
   - Карты появляются здесь при взятии из колоды
   - Можно перемещать на общее поле

### Колода

Каждая колода содержит 20 карт следующих типов:
- Атака (4 карты)
- Защита (4 карты)
- Движение (4 карты)
- Особая способность (4 карты)
- Лечение (4 карты)

## Использование

### Взятие карты из колоды

1. Нажмите кнопку **"Взять карту из колоды"** на своем поле
2. Карта появится на вашем личном поле рубашкой вверх
3. Другие игроки не видят содержимое вашего личного поля

### Переворачивание карты

1. Наведите на карту
2. Нажмите кнопку **↻** в правом верхнем углу карты
3. Карта перевернется (рубашка ↔ лицевая сторона)

### Перемещение карты

1. Зажмите карту мышкой (drag)
2. Перетащите на целевое поле (drop)
3. Карта переместится на новое поле

**Правила перемещения:**
- Из личного поля → только на общее поле
- С общего поля → обратно в свое личное поле
- Нельзя перемещать в чужое личное поле

## Классы

### Card

Представляет одну игровую карту.

```javascript
class Card {
    constructor(id, text, owner)
    // id - уникальный идентификатор
    // text - текст на карте
    // owner - владелец ('player1' или 'player2')
}
```

**Методы:**
- `createElement()` - создает DOM элемент карты
- `flip()` - переворачивает карту
- `setFlipped(flipped)` - устанавливает состояние карты

### Deck

Представляет колоду игрока.

```javascript
class Deck {
    constructor(owner)
    // owner - владелец колоды ('player1' или 'player2')
}
```

**Методы:**
- `drawCard()` - взять карту из колоды
- `getCardsCount()` - получить количество оставшихся карт

### CardManager

Управляет всеми картами и полями.

```javascript
class CardManager {
    constructor(gameBoard)
}
```

**Методы:**
- `drawCard(player)` - взять карту для игрока
- `moveCard(cardId, targetField)` - переместить карту
- `syncCardFlip(cardId, isFlipped)` - синхронизировать переворот

## События WebSocket

### Клиент → Сервер

- `card-created` - создана новая карта
- `card-moved` - карта перемещена
- `card-flipped` - карта перевернута
- `card-removed` - карта удалена

### Сервер → Клиент

- `card-created` - синхронизация создания карты
- `card-moved` - синхронизация перемещения
- `card-flipped` - синхронизация переворота
- `card-removed` - синхронизация удаления


## CSS классы

- `.cards-container` - контейнер всех карточных полей
- `.card-area` - область одного поля
- `.card-field` - само поле для карт
- `.card` - карта
- `.card-inner` - внутренний контейнер для 3D эффекта
- `.card-face` - сторона карты
- `.card-front` - лицевая сторона
- `.card-back` - рубашка
- `.flipped` - класс для перевернутой карты
- `.dragging` - класс при перетаскивании
