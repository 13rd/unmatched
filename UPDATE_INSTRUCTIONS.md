# 🚀 Инструкция по обновлению на VPS

## Шаг 1: Подготовка файлов на локальной машине

```bash
cd /home/nikita/Python/unmatched_js_table

# Создаем архив только с измененными файлами
tar -czf update.tar.gz game.js server.js rebuild.sh FIXES.md
```

## Шаг 2: Загрузка на VPS

```bash
# Замените YOUR_VPS_IP на ваш IP
scp update.tar.gz root@YOUR_VPS_IP:~/test/unmatched/
```

## Шаг 3: Применение обновлений на VPS

```bash
# Подключитесь к VPS
ssh root@YOUR_VPS_IP

# Перейдите в директорию проекта
cd ~/test/unmatched

# Распакуйте обновления
tar -xzf update.tar.gz

# Сделайте скрипт исполняемым
chmod +x rebuild.sh

# Пересоберите и перезапустите контейнер
./rebuild.sh
```

## Шаг 4: Проверка

```bash
# Просмотр логов
docker-compose logs -f

# Нажмите Ctrl+C чтобы выйти из просмотра логов
```

## Шаг 5: Тестирование

1. Откройте браузер: `http://YOUR_VPS_IP:3000/auth.html`
2. Войдите как первый игрок
3. Создайте комнату
4. Откройте консоль браузера (F12)
5. Проверьте логи - должны быть сообщения:
   ```
   Подключаемся к комнате: XXXXXX
   Роль игрока: player1
   Загрузка фишек с сервера: 8
   Обновление UI для роли: player1
   ```

6. Проверьте:
   - ✅ Фишки видны на поле
   - ✅ Имя отображается в правом верхнем углу
   - ✅ Роль "Игрок 1" отображается
   - ✅ Видно только своё поле с картами
   - ✅ Поле противника помечено и скрыто

7. В другом браузере (инкогнито):
   - Войдите как второй игрок
   - Присоединитесь к комнате
   - Проверьте те же пункты

## Если что-то не работает:

### Проблема: Фишки не видны

```bash
# Проверьте логи
docker-compose logs | grep "Создание фишек"
docker-compose logs | grep "Загрузка фишек"
```

В консоли браузера:
```javascript
gameBoard.chips.length  // Должно быть > 0
gameBoard.points.length // Должно быть > 0
```

### Проблема: Имя не отображается

В консоли браузера:
```javascript
localStorage.getItem('username')
document.getElementById('currentUsername')
```

Если элемент null - проверьте index.html

### Проблема: Видны карты противника

В консоли браузера:
```javascript
gameBoard.playerRole  // Должно быть 'player1' или 'player2'
document.querySelector('.card-area.player-area:nth-of-type(3)').classList
// Должен содержать 'hidden-cards' для противника
```

## Полезные команды:

```bash

docker-compose logs -f

# Перезапуск без пересборки
docker-compose restart

# Полная пересборка
docker-compose down
docker-compose build --no-cache
docker-compose up -d

# Проверка статуса
docker-compose ps

# Вход в контейнер
docker exec -it unmatched-game sh
```
