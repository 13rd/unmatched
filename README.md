# Многопользовательская игра с фишками

Многопользовательская версия игры на игровом поле с фишками. Несколько игроков могут одновременно подключаться к одной комнате, перемещать фишки и видеть изменения в реальном времени.

## Возможности

- **Многопользовательский режим**: несколько игроков могут играть одновременно
- **Синхронизация в реальном времени**: все действия синхронизируются через WebSocket
- **Система комнат**: создавайте комнаты и делитесь кодом с другими игроками
- **Настройка игры**: выбор цветов фишек, количества HP, количества дополнительных фишек
- **Перемещение фишек**: drag-and-drop с привязкой к точкам на поле
- **Счетчики HP**: отслеживание здоровья каждой фишки

## Установка

1. Убедитесь, что у вас установлен Node.js (версия 14 или выше)

2. Установите зависимости:
```bash
npm install
```

## Запуск

1. Запустите сервер:
```bash
npm start
```

Для разработки с автоматической перезагрузкой:
```bash
npm run dev
```

2. Откройте браузер и перейдите по адресу:
```
http://localhost:3000/setup.html
```

## Как играть

### Создание новой игры

1. Откройте `http://localhost:3000/setup.html`
2. Нажмите кнопку **"Создать новую комнату"**
3. Загрузите фоновое изображение игрового поля
4. Загрузите JSON файл с координатами точек
5. Настройте параметры для обоих игроков:
   - Выберите цвета главной и дополнительных фишек
   - Установите количество HP
   - Установите количество дополнительных фишек
6. Нажмите **"Начать игру"**
7. Скопируйте код комнаты и поделитесь им с другими игроками

### Присоединение к существующей игре

1. Откройте `http://localhost:3000/setup.html`
2. Нажмите кнопку **"Присоединиться к комнате"**
3. Введите код комнаты (6 символов)
4. Нажмите **"Подключиться"**

### Игровой процесс

- **Перемещение фишек**: кликните и перетащите фишку на новую точку
- **Изменение HP**: используйте кнопки +/- в правой панели
- **Очистка поля**: кнопка "Очистить поле" удаляет все фишки
- **Возврат к настройкам**: кнопка "Вернуться к настройкам"

## Технологии

- **Backend**: Node.js, Express, Socket.io
- **Frontend**: Vanilla JavaScript, HTML5 Canvas
- **Синхронизация**: WebSocket (Socket.io)

## Формат файла точек (JSON)

```json
[

  { "x": 200, "y": 150 },
  { "x": 300, "y": 150 }
]
```

## Устранение неполадок

**Проблема**: Не удается подключиться к серверу
- Убедитесь, что сервер запущен (`npm start`)
- Проверьте, что порт 3000 не занят другим приложением

**Проблема**: Изменения не синхронизируются
- Проверьте консоль браузера на наличие ошибок
- Убедитесь, что все игроки используют один и тот же код комнаты

**Проблема**: Фишки не отображаются
- Убедитесь, что JSON файл с точками загружен корректно
- Проверьте формат JSON файла
