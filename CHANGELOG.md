# Changelog - История изменений

## Версия 1.0.0 (2026-04-24)

### Добавлено
- ✅ Многопользовательский режим с WebSocket (Socket.io)
- ✅ Система комнат с уникальными 6-значными кодами
- ✅ Синхронизация перемещения фишек в реальном времени
- ✅ Синхронизация изменений HP между всеми игроками
- ✅ Автоматическая загрузка состояния игры для новых игроков
- ✅ Интерфейс создания/подключения к комнате
- ✅ Сохранение комнат в течение 5 минут после отключения игроков
- ✅ Автоматическая очистка неактивных комнат (старше 30 минут)

### Исправлено
- ✅ Увеличен лимит payload до 100 MB для передачи больших изображений
- ✅ Исправлена инициализация панели HP после создания фишек
- ✅ Исправлена проблема с удалением комнаты при переходе создателя на страницу игры
- ✅ Добавлена обработка события 'room-created' для создателя комнаты

### Технические детали
- Node.js сервер на Express
- WebSocket через Socket.io v4.6.1
- Максимальный размер payload: 100 MB
- Timeout пинга: 60 секунд
- Время жизни пустой комнаты: 5 минут
- Автоочистка старых комнат: каждые 10 минут

### Файлы проекта
- `server.js` - WebSocket сервер с управлением комнатами
- `setup.js` - Логика создания/подключения к комнате
- `game.js` - Игровая логика с синхронизацией
- `setup.html` - Интерфейс настройки игры
- `index.html` - Игровая страница
- `package.json` - Зависимости проекта

### Документация
- `README.md` - Полное описание проекта
- `TESTING.md` - Инструкции по тестированию
- `QUICKSTART.md` - Быстрый старт
- `CHANGELOG.md` - История изменений

### Известные ограничения
- Максимальный размер изображения: ~100 MB
- Комнаты хранятся только в памяти (при перезапуске сервера теряются)
- Нет аутентификации игроков
- Нет ограничения на количество игроков в комнате
