# Краткое руководство - Карточный движок

## Быстрый старт

### 1. Запуск игры
```bash
npm start
```
Откройте: `http://localhost:3000/setup.html`

### 2. Создание игры
- Создайте комнату
- Загрузите фон и точки
- Настройте игроков
- Начните игру

### 3. Работа с картами

#### Взять карту
```
Нажмите: "Взять карту из колоды"
Результат: Карта появится на вашем личном поле (рубашкой вверх)
```

#### Перевернуть карту
```
Нажмите: Кнопку ↻ на карте
Результат: Карта перевернется (покажет лицевую сторону или рубашку)
```

#### Переместить карту
```
Действие: Перетащите карту мышкой
Из личного поля → На общее поле ✓
С общего поля → В свое личное поле ✓
В чужое личное поле ✗ (запрещено)
```

## Структура полей

```
┌─────────────────────────────────────────┐
│         ОБЩЕЕ ПОЛЕ                      │
│  (видно всем игрокам)                   │
│  [Карта 1] [Карта 2] [Карта 3]         │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  ЛИЧНОЕ ПОЛЕ ИГРОКА 1                   │
│  (видно только Игроку 1)                │
│  [🎴] [🎴] [🎴]  [Взять карту]         │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  ЛИЧНОЕ ПОЛЕ ИГРОКА 2                   │
│  (видно только Игроку 2)                │
│  [🎴] [🎴]  [Взять карту]               │
└─────────────────────────────────────────┘
```

## Типы карт

Каждая колода содержит 20 карт:
- **Атака** (4 карты) - Атака 1, Атака 2, Атака 3, Атака 4
- **Защита** (4 карты) - Защита 1, Защита 2, Защита 3, Защита 4
- **Движение** (4 карты) - Движение 1, Движение 2, Движение 3, Движение 4
- **Особая способность** (4 карты) - Особая способность 1-4
- **Лечение** (4 карты) - Лечение 1, Лечение 2, Лечение 3, Лечение 4

## Правила приватности

✓ **Личное поле** - видите только вы
✓ **Общее поле** - видят все игроки
✓ **Рубашка карты** - скрывает содержимое
✓ **Лицевая сторона** - показывает текст карты

## Горячие клавиши

| Действие | Клавиша/Действие |
|----------|------------------|
| Взять карту | Кнопка "Взять карту из колоды" |
| Перевернуть | Кнопка ↻ на карте |
| Переместить | Drag & Drop |

## Синхронизация

Все действия синхронизируются автоматически:
- ✓ Взятие карты из колоды
- ✓ Переворачивание карты
- ✓ Перемещение карты между полями
- ✓ Загрузка состояния для новых игроков

## Пример игровой сессии

### Игрок 1:
1. Берет карту "Атака 1" из колоды → появляется на личном поле
2. Переворачивает карту → видит "Атака 1"
3. Перетаскивает на общее поле → все видят карту

### Игрок 2:
1. Видит карту "Атака 1" на общем поле
2. Берет карту "Защита 1" из своей колоды
3. Переворачивает и перемещает на общее поле
4. Обе карты видны всем игрокам

## Устранение проблем

### Карты не появляются
- Проверьте консоль браузера (F12)
- Убедитесь, что сервер запущен
- Перезагрузите страницу

### Карты не синхронизируются
- Проверьте WebSocket соединение
- Убедитесь, что все в одной комнате
- Проверьте код комнаты

### Не могу переместить карту
- Проверьте правила перемещения
- Из личного → только на общее
- С общего → только в свое личное
