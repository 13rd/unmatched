# Руководство по системе персонажей

## Обзор изменений

Система колод полностью заменена на систему персонажей. Теперь вместо выбора отдельных колод игроки выбирают персонажей, которые включают:
- Колоду из 30 карт
- Главный токен (изображение, цвет, HP)
- Дополнительные токены (изображения, цвета, количество)
- Настройки HP для дополнительных токенов

## Как создать персонажа

### 1. Откройте редактор персонажей
Перейдите на страницу `editor.html` и выберите вкладку **"Редактор персонажей"**

### 2. Заполните данные персонажа

**Имя персонажа:**
- Введите уникальное имя для вашего персонажа

**Колода (30 карт):**
- Вариант А: Загрузите готовую колоду из JSON файла
- Вариант Б: Загрузите рубашку колоды и 30 изображений карт

**Главный токен:**
- Загрузите изображение (рекомендуется 100x100 px)
- Выберите цвет токена
- Установите HP по умолчанию (обычно 10-20)

**Дополнительные токены:**
- Укажите количество (0-10)
- Для каждого токена:
  - Загрузите изображение (рекомендуется 100x100 px)
  - Выберите цвет
- Установите HP для всех дополнительных токенов (обычно 1-5)

### 3. Экспортируйте персонажа
- Нажмите **"Экспортировать персонажа (JSON)"**
- Сохраните файл в папку `heroes/characters/`

### 4. Оптимизация (важно!)
Если файл получился больше 1 МБ, следуйте инструкциям в `CHARACTER_OPTIMIZATION.md`

## Как выбрать персонажа в игре

### 1. Откройте настройки игры
Перейдите на страницу `setup.html`

### 2. Выберите режим
- **Создать новую комнату** - для создания игры
- **Присоединиться к комнате** - для входа в существующую игру

### 3. Настройте игровое поле
- Загрузите фоновое изображение
- Загрузите файл с точками (JSON)

### 4. Выберите персонажей
В разделе **"Выбор персонажей"** вы увидите галерею доступных персонажей:
- Для Игрока 1: выберите персонажа из левой галереи
- Для Игрока 2: выберите персонажа из правой галереи

Каждая карточка персонажа показывает:
- Изображение главного токена
- Имя персонажа
- HP главного токена
- Количество помощников

### 5. Начните игру
Нажмите **"Начать игру"**

## Структура файла персонажа

```json
{
  "name": "Имя Персонажа",
  "deck": {
    "backImage": "путь/к/рубашке.png",
    "cards": [
      {"image": "путь/к/карте1.png", "text": "Название карты 1"},
      ...30 карт всего
    ]
  },
  "mainToken": {
    "image": "путь/к/главному_токену.png",
    "color": "#e53e3e",
    "hp": 14
  },
  "extraTokens": [
    {
      "image": "путь/к/доп_токену1.png",
      "color": "#3182ce"
    },
    ...
  ],
  "extraTokenHP": 1
}
```

## Рекомендации по изображениям

**Токены:**
- Формат: PNG или SVG
- Размер: 100x100 px
- Изображение должно хорошо смотреться в круге

**Карты:**
- Формат: PNG или JPEG
- Размер: 200x280 px (соотношение 5:7)
- Рубашка колоды должна быть одинаковой для всех карт

**Оптимизация:**
- Используйте внешние файлы вместо base64
- Сжимайте изображения перед загрузкой
- Используйте SVG для простых иконок

## Устранение проблем

**Персонажи не загружаются:**
- Проверьте, что файлы находятся в `heroes/characters/`
- Убедитесь, что JSON файл корректный
- Проверьте консоль браузера на ошибки

**Изображения не отображаются:**
- Проверьте пути к изображениям в JSON
- Убедитесь, что файлы изображений существуют
- Проверьте права доступа к файлам

**Медленная загрузка:**
- Следуйте инструкциям в `CHARACTER_OPTIMIZATION.md`
- Используйте внешние файлы вместо base64
- Уменьшите размер изображений

## Миграция со старой системы

Старая система колод больше не поддерживается. Для миграции:
1. Создайте персонажа в редакторе
2. Загрузите вашу старую колоду через "Загрузить колоду из JSON"
3. Добавьте изображения токенов
4. Экспортируйте как персонажа
