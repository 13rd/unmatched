# Руководство по созданию пользовательских колод

## Обзор

Теперь каждый игрок может использовать свою уникальную колоду из 30 карт с собственными изображениями. Редактор колод позволяет легко создавать и экспортировать колоды для использования в игре.

## Создание колоды

### Шаг 1: Подготовка изображений

Подготовьте следующие изображения:
- **1 изображение рубашки** - будет отображаться на обратной стороне всех карт
- **30 изображений карт** - лицевая сторона каждой карты

**Рекомендации:**
- Формат: PNG, JPG, WEBP
- Соотношение сторон: 2:3 (например, 200x300px)
- Размер файла: до 500KB на карту (для быстрой загрузки)
- Качество: достаточное для чтения текста на карте

### Шаг 2: Открытие редактора

1. Запустите сервер: `npm start`
2. Откройте в браузере: `http://localhost:3000/editor.html`
3. Перейдите на вкладку **"Редактор колод"**

### Шаг 3: Загрузка рубашки

1. Нажмите **"Загрузить рубашку колоды"**
2. Выберите изображение рубашки
3. Проверьте превью справа

### Шаг 4: Загрузка карт

1. Нажмите **"Загрузить 30 изображений карт"**
2. Выберите все 30 изображений одновременно (Ctrl+A или Cmd+A)
3. Дождитесь загрузки всех карт
4. Проверьте сетку с превью всех карт

**Управление картами:**
- Каждая карта пронумерована (1-30)
- Кнопка **×** удаляет карту
- Можно добавить новые карты до достижения 30

### Шаг 5: Экспорт колоды

1. Убедитесь, что загружено ровно 30 карт
2. Нажмите **"Экспортировать колоду (JSON)"**
3. Сохраните файл `deck.json`

## Использование колоды в игре

### Загрузка колоды

1. Откройте `http://localhost:3000/setup.html`
2. Найдите раздел **"Колоды карт"**
3. Для каждого игрока:
   - Нажмите **"Загрузить колоду (JSON)"**
   - Выберите файл `deck.json`
   - Проверьте, что отображается имя файла

### Начало игры

1. Настройте остальные параметры (фон, точки, цвета)
2. Нажмите **"Начать игру"**
3. В игре нажмите **"Взять карту из колоды"**
4. Карта с вашим изображением появится на поле!

## Формат JSON файла

```json
{
  "backImage": "data:image/png;base64,iVBORw0KGgoAAAANS...",
  "cards": [
    {
      "text": "Атака 1",
      "image": "data:image/png;base64,iVBORw0KGgoAAAANS..."
    },
    {
      "text": "Защита 1",
      "image": "data:image/png;base64,iVBORw0KGgoAAAANS..."
    },
    ...
    // Всего 30 карт
  ]
}
```

### Поля:

- `backImage` - изображение рубашки в формате base64
- `cards` - массив из 30 карт
  - `text` - название карты (опционально)
  - `image` - изображение карты в формате base64

## Редактирование существующей колоды

1. Откройте редактор колод
2. Нажмите **"Импортировать колоду (JSON)"**
3. Выберите файл колоды
4. Редактируйте:
   - Удаляйте ненужные карты (кнопка ×)
   - Добавляйте новые карты
   - Меняйте рубашку
5. Экспортируйте обновленную колоду

## Советы и рекомендации

### Оптимизация размера

Если файл колоды слишком большой (>10MB):
1. Уменьшите разрешение изображений (рекомендуется 200x300px)
2. Используйте сжатие JPEG вместо PNG
3. Оптимизируйте изображения через онлайн-сервисы

### Дизайн карт

**Хорошие практики:**
- Используйте читаемые шрифты
- Контрастные цвета для текста и фона
- Единый стиль для всех карт колоды
- Четкие границы карт

**Избегайте:**
- Слишком мелкий текст
- Перегруженный дизайн
- Низкое качество изображений

### Организация колод

Создайте папку для колод:
```
/decks
  /player1
    - attack_deck.json
    - defense_deck.json
  /player2
    - magic_deck.json
```

### Тестирование

1. Создайте тестовую колоду с простыми изображениями
2. Загрузите в игру
3. Проверьте:
   - Все карты загружаются
   - Изображения отображаются корректно
   - Переворачивание работает
   - Синхронизация между игроками

## Примеры использования

### Пример 1: Колода для настольной игры

Создайте колоду на основе существующей настольной игры:
1. Сфотографируйте или отсканируйте карты
2. Обрежьте изображения до одинакового размера
3. Загрузите в редактор
4. Экспортируйте и используйте

### Пример 2: Собственная игра

Создайте уникальную колоду:
1. Нарисуйте карты в графическом редакторе
2. Экспортируйте каждую карту как PNG
3. Создайте колоду в редакторе
4. Поделитесь JSON файлом с друзьями

### Пример 3: Тематические колоды

Создайте колоды для разных персонажей:
- Колода воина (атаки и защита)
- Колода мага (заклинания)
- Колода лекаря (исцеление)

## Устранение проблем

### Колода не загружается

**Проблема:** Ошибка при загрузке JSON
- Проверьте формат файла
- Убедитесь, что в колоде ровно 30 карт
- Проверьте размер файла (<50MB)

### Изображения не отображаются

**Проблема:** Карты показывают только текст
- Проверьте, что поле `image` заполнено
- Убедитесь, что изображения в формате base64
- Попробуйте пересоздать колоду

### Медленная загрузка

**Проблема:** Игра долго загружается
- Уменьшите размер изображений
- Используйте JPEG вместо PNG
- Оптимизируйте изображения

## Технические детали

### Ограничения

- Максимум 30 карт в колоде (строго)
- Рекомендуемый размер файла: до 20MB
- Поддерживаемые форматы: PNG, JPG, WEBP
- Изображения хранятся в base64

### Совместимость

- Работает во всех современных браузерах
- Требуется JavaScript
- Локальное хранение в sessionStorage

### Безопасность

- Все данные хранятся локально
- Изображения не загружаются на сервер
- JSON файлы можно безопасно делиться
